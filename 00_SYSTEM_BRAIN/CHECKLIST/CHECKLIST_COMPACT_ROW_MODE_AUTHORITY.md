# Checklist Compact Row Mode Authority

**Phase:** `PHASE_CHECKLIST_08_COMPACT_ROW_MODE`  
**Status:** ACTIVE

## Authority Scope

Checklist row layout density and compact visual presentation.

## Allowed Changes

- CSS spacing/density tuning
- Compact metadata grouping and safe truncation
- Row action spacing/alignment polish
- Diagnostics and governance artifacts

## Forbidden Changes

- No business logic change
- No persistence change
- No schema change
- No workflow/deep-link contract changes
- No hiding of critical row actions/signals

## Completion Requirements

- Rows are compacted without losing usability.
- Focus row remains prominent.
- Counts/signals and copy-link remain visible.
- Existing runtime contracts (focus/progress/copy-link/comment/toast/interaction/link/sheet) remain intact.

# docs/training — Manuals

Hướng dẫn vận hành cho người dùng cuối HOME_ALERT.

## Files

| File | Audience | Khi nào đọc |
|------|----------|-------------|
| `HOME_ALERT_OPERATOR_MANUAL.md` | Operator | Trước go-live + onboarding |
| `HOME_ALERT_SUPERVISOR_MANUAL.md` | Supervisor / Team Lead | Trước go-live + weekly review |

## Đọc theo thứ tự

1. Operator đọc `HOME_ALERT_OPERATOR_MANUAL.md`.
2. Supervisor đọc cả 2 file (hiểu việc operator trước khi giám sát).
3. Sau 1 tuần go-live: cả 2 quay lại đối chiếu checklist 5' đầu/cuối ngày + weekly review.
